 PROJECT DESCRIPTION (For Report / Synopsis)
MindMitra is a full-stack mental health and wellness platform designed especially for college students. Many students face stress, anxiety, exam fear, sleep issues, and depression but hesitate to seek help.

MindMitra provides a safe, private, and friendly digital space to:

- Mood Tracking: Daily mood logging with Emoji + Text + Intensity + Face Scan AI.
- Face Emotion Detection: Live camera scans emotion (Happy, Sad, Anxious, Calm) and suggests mood.
- Smart Journal: Write thoughts, auto-tag feelings, and save securely.
- Psychological Assessments: PHQ-9, GAD-7, PSS tests with instant score and level.
- Wellness Hub: Breathing exercise (4-7-8), Meditation, Music Therapy, Motivational Quotes.
- Find Therapist: Filter by speciality, language, price and book appointment. Data saved to MySQL.
- Progress Report: Charts of mood, journal count, wellness streak.
- Community Support: Anonymous posts, chatbot support, and Kiran Helpline 1800-599-0019 integration.
- Privacy First: All data encrypted, exportable JSON, and stored in XAMPP MySQL (16 tables).

Tech Stack: HTML, CSS, JS (Poppins UI, Light/Dark Mode), http://Node.js + Express Backend, MySQL (XAMPP), REST APIs.

Goal: To make mental health support accessible, stigma-free, and available 24x7 for every student.
